# Brief

## Scop
Prezența digitală a brandului personal **Daniel Popescu**, antrenor de tenis și antreprenor sportiv.
Prima livrare: website personal cu jurnal, administrare de conținut și contact funcțional.

**Succesul v1:** un vizitator înțelege rapid cine este Daniel, ce oferă, cum gândește tenisul și cum îl contactează.

## Public și piață
- România, limba română implicită; engleza se activează când există conținut tradus și verificat.
- Vizitatori care caută antrenamente de tenis; cititori interesați de tehnică, pregătire și observații despre tenis; potențiali colaboratori.

## Poziționare și ton
Tenis, pregătire atentă, progres, stil de viață activ. Ton competent, calm, direct, apropiat, atent la detalii.
„Beyond the Game” este semnătură secundară (footer), nu mesaj principal.

## Constrângeri
- Cod, bază de date și media controlate de proprietar; găzduire portabilă; fără Shopify, website builder sau CMS proprietar.
- Fără informații inventate. Conținutul public provine din CMS și este validat de Daniel.
- Mobil întâi; ținte: Lighthouse mobil Performance ≥ 90, LCP ≤ 2,5 s, CLS ≤ 0,1, INP ≤ 200 ms.
- Cost zero de licență pentru instrumentele auxiliare; costurile de infrastructură se aprobă separat (`docs/TOOLS.md`).

## Ce NU construim acum
Conturi de jucători, dashboarduri, marketplace, mesagerie, clasamente, rezervări, checkout, inventar, abonamente,
IoT, chatbot public, mockupuri de produse, pagini goale pentru idei viitoare. Direcțiile acestea: `docs/ROADMAP.md`.
